# Лабораторная работа 4

## Условие задачи
Контроль качества на фабрике игрушек пропускает партию, если вес каждой из трех случайно выбранных игрушек (A, B, C грамм) кратен семи. Это свидетельствует о соблюдении технологических норм. Запишите условие принятия партии.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить переменные:
   - `a, b, c` — целочисленные переменные для хранения веса трех игрушек.
   - `condition` — целочисленная переменная для хранения результата логического условия (1 - истина, 0 - ложь).
3. Запросить у пользователя ввод трех весов (A, B, C) в граммах.
4. Считать три числа в переменные `a`, `b` и `c`.
5. Вычислить логическое условие: проверить, что остаток от деления каждого веса на 7 равен нулю.
6. Объединить проверки с помощью логического «И» (`&&`): `(a % 7 == 0) && (b % 7 == 0) && (c % 7 == 0)`.
7. Вывести результат на экран (1 - партия принята, 0 - отклонена).
8. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>
#include <locale.h>

int main() 
{
    setlocale(LC_ALL, "Russian");

    int a, b, c;
    int condition;

    printf("=== КОНТРОЛЬ КАЧЕСТВА ИГРУШЕК ===\n");
    printf("Введите вес трех игрушек (A, B, C) в граммах: ");

    scanf("%d %d %d", &a, &b, &c);

    condition = (a % 7 == 0) && (b % 7 == 0) && (c % 7 == 0);

    printf("Партия принята (1 - да, 0 - нет): %d\n", condition);

    return 0;
}
```
